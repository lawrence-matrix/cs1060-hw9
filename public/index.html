CS1060 Homework 9 Repository

This repository contains a small matrix utility library, unit tests, CI workflow configuration, and documentation for HW9.

  • AGENTS.md - project context and testing instructions
  • src/matrix.py - matrix operations implementation
  • tests/test_matrix.py - comprehensive pytest suite
  • .github/workflows/ci.yml - CI pipeline with Vercel deployment support

To deploy this project to Vercel, configure the repository secrets VERCEL_TOKEN, VERCEL_ORG_ID, and VERCEL_PROJECT_ID.

The CI pipeline is designed to run tests on all pushes and pull requests. When configured, it can deploy feature branches to Vercel preview and the main branch to production.
